# قواعد اتساق الـ API (API Consistency Rules)

**لماذا هذا الملف موجود؟**
لضمان توحيد شكل الردود (JSON Structure) عبر كل الـ APIs.

## القواعد:
1. **الهيكل:** الالتزام بهيكل `success`, `data`, `errors` في كل رد.
2. **الترقيم:** استخدام الترقيم للأخطاء (HTTP Status Codes) بشكل صحيح.
3. **التوثيق:** يجب تحديث ملفات الـ APIs عند إضافة أي Endpoint جديد.

## المفاضلات (Trade-offs):
- فرض هيكل موحد يضيف قيوداً على المطور، لكنه يسهل استهلاك البيانات من تطبيق Flutter.

## المخاطر (Risks):
- بطء تطوير ميزات جديدة بسبب الالتزام الصارم بالهيكل.

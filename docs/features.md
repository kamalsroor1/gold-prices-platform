# ميزات المشروع (Features)

**لماذا هذا الملف موجود؟**
لتوثيق ميزات النظام بشكل مفصل للمطورين.

## الميزات:
1. **عرض الأسعار:** تحديث آلي وعرض أسعار الذهب الخام.
2. **قائمة السبايك:** عرض السبايك والعملات مع تصنيفات.
3. **الحاسبة:** حاسبة ذكية لحساب المصنعية والضريبة.
4. **التنبيهات:** تنبيهات عند الوصول لسعر معين.
5. **قائمة المتابعة:** حفظ المنتجات المفضلة.

## المفاضلات (Trade-offs):
- إعطاء الأولوية لميزات القيمة المضافة مقابل الميزات الثانوية.

## المخاطر (Risks):
- تعقيد واجهة التطبيق إذا زادت الميزات بشكل غير منظم.

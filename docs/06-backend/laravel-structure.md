# هيكلة مشروع Laravel

**لماذا هذا الملف موجود؟**
يوضح تنظيم ملفات المشروع، مما يضمن اتساق العمل بين أعضاء الفريق وتسهيل العثور على الملفات.

## الهيكلية المقترحة (محدثة):
- `app/Domains/{Domain}/Models`: نماذج البيانات.
- `app/Domains/{Domain}/Repositories`: التعامل مع قاعدة البيانات.
- `app/Domains/{Domain}/Services`: منطق العمل.
- `app/Domains/{Domain}/Http/Resources`: تحويل البيانات للـ API.
- `app/Domains/{Domain}/Http/Controllers`: المتحكمات.

## المفاضلات (Trade-offs):
- تنظيم صارم للملفات يسهل العمل طويل الأمد، ولكنه يتطلب التزاماً من المطورين.

## المخاطر (Risks):
- التهاون في اتباع التنظيم سيؤدي إلى "تشتت" الكود مع مرور الوقت.

## بدائل تم النظر فيها:
- الهيكلية الافتراضية للارافيل: تم رفضها لأنها لا تكفي للمشاريع التوسعية وتؤدي إلى تراكم الكود.

# خريطة الوثائق (Docs Map)

**لماذا هذا الملف موجود؟**
لتوفير فهرس سريع لكل الملفات في النظام، مما يسهل البحث والوصول للمعلومات.

## المحتويات:
- `00-overview`: النظرة العامة والمواصفات.
- `01-product`: متطلبات المنتج وقصص المستخدمين.
- `02-architecture`: المعمارية التقنية.
- `03-database`: تصميم قاعدة البيانات.
- `04-pricing-engine`: معادلات التسعير.
- `05-api`: تصميم الواجهات البرمجية.
- `06-backend`: تصميم الخلفية البرمجية.
- `07-mobile`: تصميم تطبيق الموبايل.
- `08-performance`: تحسين الأداء.
- `09-security`: معمارية الأمان.
- `10-devops`: النشر والإدارة.
- `11-tasks`: نظام المهام.
- `12-roadmap`: خارطة طريق المشروع.
- `13-ai-rules`: قواعد عمل الذكاء الاصطناعي.

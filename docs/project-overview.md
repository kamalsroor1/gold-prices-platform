# نظرة عامة على المشروع

هذه الوثيقة توضح المواصفات الفنية والتصميم الهندسي لمنصة تتبع أسعار الذهب والسبائك. تهدف المنصة إلى توفير معلومات دقيقة ومحدثة (تحديثات كل ساعة) لأسعار الذهب الخام (عيار 24، 21، 18)، وسبائك الذهب، والعملات الذهبية من مختلف الشركات المصنعة عبر دول متعددة. صُمم النظام بهيكلية تعتمد على خلفية برمجية (Backend) مبنية بـ Laravel لتعمل كمركز بيانات مركزي، وتطبيق هاتف محمول (Flutter) للمستخدمين النهائيين، مع مراعاة خاصة للعمل بكفاءة ضمن قيود الاستضافة المشتركة (Hostinger Shared Hosting).

### لماذا هذا القسم موجود؟
يقدم هذا القسم فهمًا عالي المستوى للغرض من المشروع، والجمهور المستهدف، والمكونات الأساسية، مما يضع السياق لجميع الوثائق الفنية اللاحقة.

### المفاضلات (Trade-offs):
- **قيود الاستضافة المشتركة:** تأثرت المعمارية بشكل كبير بالحاجة للعمل ضمن محدودية موارد الاستضافة المشتركة، مع إعطاء الأولوية للكفاءة وتقليل استهلاك الموارد للمهام الخلفية.

### المخاطر (Risks):
- **الاعتماد على APIs خارجية:** الاعتماد على مصادر بيانات خارجية لأسعار الذهب يقدم مخاطرة في عدم توفر البيانات أو عدم دقتها.
- **حدود موارد Hostinger:** تجاوز حدود المعالج (CPU) أو الذاكرة (RAM) على الاستضافة المشتركة قد يؤدي إلى تدهور الأداء أو انقطاع الخدمة.

### بدائل تم النظر فيها:
- **استضافة مخصصة (Dedicated Server) أو سحابية:** تم رفضها بسبب قيود الميزانية والمتطلبات الصريحة للعمل على استضافة مشتركة.
- **تحديثات لحظية (كل ثانية):** تم رفضها بسبب التكلفة العالية للموارد واحتمالية تجاوز حدود الاستضافة المشتركة.

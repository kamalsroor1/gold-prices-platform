# معالجة الأخطاء (Error Handling)

**لماذا هذا الملف موجود؟**
يوضح هذا الملف هيكلية رسائل الأخطاء لضمان اتساق الردود التي يتلقاها تطبيق Flutter، مما يسهل معالجتها في واجهة المستخدم.

## الهيكل القياسي للرد في حالة الخطأ:

```json
{
  "success": false,
  "message": "رسالة الخطأ للمستخدم",
  "errors": {
    "field_name": ["تفاصيل الخطأ"]
  }
}
```

## المفاضلات (Trade-offs):
- توفير تفاصيل الأخطاء يساعد في التطوير، ولكنه قد يكشف معلومات حساسة عن النظام إذا لم يتم إخفاؤها في بيئة الإنتاج.

## المخاطر (Risks):
- إرسال تفاصيل تقنية للأخطاء قد يشكل ثغرة أمنية.

## بدائل تم النظر فيها:
- إرسال كود خطأ HTTP فقط: تم رفضه لأنه غير كافٍ لتوضيح الخطأ للمستخدم في التطبيق.

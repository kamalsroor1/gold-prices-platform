# نقاط الاتصال البرمجية (API Endpoints)

**لماذا هذا الملف موجود؟**
يوثق هذا الملف جميع الـ Endpoints المتاحة، ليكون مرجعاً للمطورين الذين يعملون على تطوير تطبيق Flutter.

## الـ Endpoints الرئيسية:

1. **`GET /api/v1/countries`**
   - **الوصف:** جلب قائمة الدول المفعلة.
   - **الاستخدام:** شاشة اختيار الدولة.

2. **`GET /api/v1/prices/latest?country_id={id}`**
   - **الوصف:** جلب أحدث أسعار الذهب الخام (24k, 21k, 18k).
   - **الاستخدام:** الواجهة الرئيسية.

3. **`GET /api/v1/prices/history?country_id={id}&period={week|month}`**
   - **الوصف:** جلب سجل أسعار الذهب التاريخي.
   - **الاستخدام:** الرسوم البيانية.

4. **`GET /api/v1/bullions?country_id={id}`**
   - **الوصف:** جلب السبايك والعملات المتاحة وأسعارها المحسوبة.
   - **الاستخدام:** شاشة السبايك.

## المفاضلات (Trade-offs):
- توفير الـ Endpoints بشكل مفصل يسهل العمل، ولكنه يزيد من عدد الطلبات من التطبيق للسيرفر.

## المخاطر (Risks):
- استهلاك موارد السيرفر إذا تم طلب بيانات كبيرة جداً في كل مرة.

## بدائل تم النظر فيها:
- دمج كافة البيانات في Endpoint واحد: تم رفضه لتقليل حجم الـ Payload وتسهيل إدارة الكاش لكل نوع بيانات على حدة.

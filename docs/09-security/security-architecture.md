# معمارية الأمان (Security Architecture)

**لماذا هذا الملف موجود؟**
لحماية بيانات المستخدمين، منع الهجمات الإلكترونية، وضمان استمرارية الخدمة.

## تدابير الأمان:
- **API Authentication:** استخدام Laravel Sanctum لتأمين الوصول.
- **Rate Limiting:** تحديد عدد الطلبات لكل مستخدم/IP لمنع الهجمات.
- **Input Validation:** تنقية جميع مدخلات المستخدم لمنع SQL Injection و XSS.
- **HTTPS:** إجبار جميع الاتصالات عبر بروتوكول آمن.

## المفاضلات (Trade-offs):
- تطبيق تدابير أمنية مشددة قد يزيد قليلاً من زمن الاستجابة، لكنه ضروري لحماية النظام.

## المخاطر (Risks):
- محاولات اختراق APIs لاستنزاف الموارد أو سرقة البيانات.

## بدائل تم النظر فيها:
- **OAuth2:** تم رفضه لتعقيد إعداده والحاجة لموارد إضافية، Sanctum كافٍ جداً لمشروعنا.

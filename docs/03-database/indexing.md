# استراتيجية الفهرسة (Indexing Strategy)

**لماذا هذا الملف موجود؟**
يحدد هذا الملف الفهارس المطلوبة لتحسين أداء استعلامات قاعدة البيانات، لضمان استجابة سريعة للنظام، خاصة عند زيادة حجم البيانات التاريخية.

## الفهارس المطلوبة:

1. **`idx_country_timestamp`**: (على جدول `gold_prices`) لتحسين الاستعلام عن الأسعار الخاصة بدولة معينة خلال فترة زمنية محددة.
2. **`idx_brand_product`**: (على جدول `pricing_rules`) لتحسين البحث عن قواعد التسعير الخاصة بمنتج معين لشركة معينة.
3. **`idx_active_country`**: (على جدول `countries`) لتسريع عملية جلب الدول النشطة فقط.
4. **`idx_fetched_at`**: (على جدول `gold_prices`) لتسريع ترتيب وجلب أحدث الأسعار المحدثة.

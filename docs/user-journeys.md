# رحلات المستخدم (User Journeys)

**لماذا هذا الملف موجود؟**
لفهم كيفية تفاعل المستخدم مع النظام.

## الرحلات:
1. **المستخدم الجديد:** فتح التطبيق -> اختيار الدولة -> عرض الأسعار.
2. **المستثمر:** فتح التطبيق -> تصفح السبايك -> استخدام الحاسبة لحساب التكلفة.
3. **المتابع:** ضبط تنبيه لسعر معين -> استقبال إشعار.

## المخاطر (Risks):
- تعقيد الرحلة قد يؤدي لخروج المستخدم.
